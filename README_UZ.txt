Hambi Lite — sariq/qora zamonaviy Android prototipi

Funksiyalar:
- Birinchi ochishda 4 xonali PIN o'rnatish va keyingi ochishlarda tekshirish
- PIN-kodni profil bo'limidan o'zgartirish
- Bosh sahifa, tariflar, internet paketlari va profil bo'limlari
- USSD terish oynasini ochish: *102#, *103#, *106#, *105#
- Beeline rasmiy sahifalariga havolalar

Muhim: bu mustaqil prototip, Beeline/Hambi rasmiy ilovasi emas. Rasmiy API ulanmaganligi sabab balans, tarif xaridi yoki paket sotib olish ilova ichida avtomatik bajarilmaydi. USSD va rasmiy sayt orqali ishlaydi.

Loyihani Android Studio'da oching, Gradle sinxronizatsiyasini bajaring va Run tugmasini bosing. APK uchun Build > Build APK(s) ni tanlang.
